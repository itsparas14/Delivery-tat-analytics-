# Delivery TAT Analytics Dashboard

Power BI dashboard built for monitoring logistics performance across multiple courier partners.

---

## Project Objective

Track delivery performance, courier efficiency, and warehouse turnaround time to identify operational bottlenecks.

---

## Business Problem

The company ships over 1,600 orders every month through 12 logistics partners.

The management lacked visibility into

- Delivery delays
- Courier performance
- Warehouse TAT
- Customer-wise performance

---

## Solution

Developed an interactive Power BI dashboard using DAX and Power Query.

Features include

- Delivery TAT
- Dispatch TAT
- On-Time Delivery %
- Courier Ranking
- Customer Performance
- SLA Monitoring
- Weekly Trend Analysis
